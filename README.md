# Distributed Intelligent E-Commerce

Bu proje, mikroservis mimarisi ve yapay zeka destekli modüller ile geliştirilmiş dağıtık ve akıllı bir e-ticaret platformudur. Sistem, yüksek ölçeklenebilirlik, dinamik öneri mekanizmaları ve güvenli işlem yönetimi sunarak modern e-ticaret ihtiyaçlarını karşılamayı hedeflemektedir.
